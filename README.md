# 🧩 Project & Task Management Dashboard

A full-stack project management tool that allows users to create, update, and manage projects and tasks with role-based assignments.

## 🔧 Tech Stack

- **Frontend**: React, Redux, Material-UI
- **Backend**: Node.js, Express
- **Database**: MongoDB
- **Authentication**: JWT
- **State Management**: Redux

---

## ✨ Features

- 🔐 User Sign Up / Login (JWT-based)
- 📁 Create, Edit, and Delete Projects
- ✅ Assign users to Projects
- 📋 Create, Edit, and Delete Tasks under Projects
- 📌 Assign Tasks to Team Members
- 📊 Dashboard for viewing all Projects and Tasks
- 🎨 UI powered by Material-UI
